# CRUD com Java e Spring Boot

## 📌 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar os conceitos de desenvolvimento de APIs REST utilizando Java e Spring Boot.

Durante o desenvolvimento, trabalhei com a estruturação de uma aplicação backend, criação de endpoints HTTP e conceitos de persistência de dados, buscando compreender na prática como funciona a comunicação entre as diferentes camadas de uma aplicação.

## 🚀 Tecnologias utilizadas

* **Java** — linguagem de programação.
* **Spring Boot** — framework para desenvolvimento de aplicações Java.
* **Spring Web** — criação de endpoints e APIs REST.
* **Spring Data JPA** — abstração do acesso e da persistência de dados.
* **H2 Database** — banco de dados utilizado durante o desenvolvimento.
* **Lombok** — redução de código repetitivo, como getters, setters e construtores.
* **Maven** — gerenciamento de dependências e construção do projeto.

## ⚙️ Conceitos praticados

* Desenvolvimento de APIs REST.
* Criação e organização de controllers e services.
* Mapeamento de requisições HTTP.
* Operações CRUD (*Create, Read, Update e Delete*).
* Utilização de anotações do Spring Boot.
* Persistência de dados com JPA.
* Configuração de banco de dados H2.
* Gerenciamento de dependências com Maven.

## 📚 Objetivo

Consolidar meus conhecimentos em Java e aprofundar meus estudos em desenvolvimento backend, aplicando os conceitos do Spring Boot na construção de uma API e compreendendo melhor o funcionamento de suas principais ferramentas.
